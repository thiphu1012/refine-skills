# refine-skills

Claude Code plugin marketplace containing the `refine` plugin.

## Install

```
/plugin marketplace add thiphu1012/refine-skills
/plugin install refine@team-skills
```

Restart Claude Code if prompted.

## Use

```
/refine:refine-opus-5-5 <your task prompt>
```

Claude proposes a task contract (goal, scope, constraints, success criteria, assumptions) and waits. Reply `run`, `edit: <change>`, `original`, or `cancel`.

## Update

```
/plugin marketplace update team-skills
```
